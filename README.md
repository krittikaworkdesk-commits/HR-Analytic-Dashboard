# HR-Analytic-Dashboard
An interactive Power BI dashboard analysing employee turnover, workforce demographic, and retention patterns.

Key Metrics -
Total Employees - 1470
Attrition Count - 237
Average Age - 37
Average Salary - $6.5k

Key Insights -
1.Education-Life Sciences(41%) has the highest turnover
2.Age group-Highest exists in the 26-35 age bracket
3.Salary-Maximum turnover in the lowest pay band (upto 5k:163 exists)
4.Tenure-Critical drop-off seen within the first 1-2 years at the company

Final Conclusion -
High turnover is primarily driven by lower_salaried ypong professionals in the early career stages (first 1-2 years).

Tools Used -
Power BI desktop, Power query, DAX, Excel/CSV dataset
